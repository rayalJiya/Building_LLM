# Building LLMs from Scratch 🧠

A hands-on learning repository where I am exploring and implementing the fundamental concepts behind Large Language Models (LLMs) from scratch.

The goal of this repository is to understand what happens underneath modern LLMs rather than only using high-level frameworks and APIs.

---

## 📌 Current Progress

The repository currently focuses on **tokenization** and **next-token prediction**, which are important building blocks in the language-modeling pipeline.

### Current implementations

- Character-level tokenization
- Word-level tokenization
- Byte Pair Encoding (BPE)
- Next-token prediction using input-target pairs
